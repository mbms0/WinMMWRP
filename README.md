<p align="center">
  <h1>Windows Multimedia Wrapper</h1>
  <br />
  A group of functions, that allows you to bypass the Windows Multimedia API, thus getting rid of the lag caused by its slow buffer system.
</p>

# What does this do?
Windows Multimedia Wrapper (as the name says), wraps around the default multimedia library in Windows, **winmm.dll**, and allows users to circumvent the extremely slow **midiOut\*** calls that Microsoft introduced in Windows 8.1 and Windows 10.
